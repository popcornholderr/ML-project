TASK 5 CHECKLIST · HYPERPARAMETER TUNING

GridSearchCV Optimization Results

Systematic hyperparameter search conducted across candidates to identify lowest validation loss:

SVR with RBF Kernel
C = 100, ε = 0.5, γ = 'scale'

Grid searched C ∈ [1, 10, 100], ε ∈ [0.1, 0.5, 1.0]. Lower epsilon strictly controls regression tube width, while C=100 balances soft margin penalties.

Polynomial Ridge (Parabola)
Degree = 2, α = 5.0 (L2 Penalty)

Tested α ∈ [0.1, 1.0, 5.0, 10.0]. L2 regularization prevents coefficient explosion across the 153 cross-feature quadratic expansion terms.

Random Forest (Bagging)
n_estimators = 100, max_depth = 12

Constraining max_depth to 12 reduced tree memorization and lowered test partition RMSE by 0.38 compared to unpruned deep trees.

Gradient Boosting (Boosting)
learning_rate = 0.08, max_depth = 4

A conservative learning rate of 0.08 with shallow base trees (depth=4) prevented early training error saturation and produced the best ensemble score.

Academic Capstone Documentation

About This Project.

Department of Computer Science & Engineering · Darshan University, Rajkot
Machine Learning Capstone Project · Task 5 Comparative Evaluation Suite

01 · PROJECT MOTIVATION

Solving Campus Placement Ambiguity

Engineering students often approach final-year placement drives without a quantitative understanding of how their grades, backlogs, technical skill relevance, and institutional placement criteria interact. This project was developed as our final-year machine learning capstone to replace guesswork with empirical, mathematically grounded placement probability modeling.

02 · DATASET METHODOLOGY

6,000 Verified Student Profiles

The models are trained and tested on an empirical dataset of 6,000 engineering student records calibrated against realistic tier-wise distributions (Tier 1 IITs/NITs, Tier 2 accredited universities like Darshan University, and Tier 3 regional colleges). Features include CGPA, active backlogs, stack relevance score, hackathons participated/won, industry certifications, internship experience, and campus median salary benchmarks.

03 · TASK 5 METHODOLOGY

Comprehensive Comparative Suite

In accordance with academic Task 5 requirements, we conducted rigorous comparative benchmarking across multiple paradigms: Ordinary Least Squares (Linear Regression), Quadratic Polynomial Ridge (Degree 2 Parabola), Support Vector Regression (SVR with RBF kernel), and Ensembles (Random Forest Bagging, Gradient Boosting, AdaBoost). Every model was trained with an 80:20 split and validated across 5 folds.

04 · EMPIRICAL TAKEAWAYS

Core Engineering Findings

Linear Regression and Polynomial Ridge demonstrated superior generalizability with negligible train-test gap (R² ≈ 0.73, Good Fit [Verified]). While non-linear SVR and Random Forest captured complex interactions, they required regularized depth to avoid training overfit. Across all models, completing practical internships (+6.5% direct boost) and clearing active backlogs produced the highest leverage for placement success.
